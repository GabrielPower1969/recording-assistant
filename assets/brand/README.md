# assets/brand/

The coach's icon is the FlowGT Recorder icon (an aluminium plate, two reels, three keys with the red
record dot). It is copied from that project's `design/brand/` (branch `mac/next-round`, commit dc3e328) and
only scaled here; it is never redrawn. To update it, copy again from there.

| File | Size | Made from | Used for |
|---|---|---|---|
| `icon-16.png` | 16 × 16 | `icon-small-512.png` | browser tab |
| `icon-32.png` | 32 × 32 | `icon-small-512.png` (FlowGT's `32x32.png`) | browser tab on high-density screens |
| `mark-96.png` | 96 × 96 | `icon-small-512.png` | the mark in the page: top bar (24 px) and the list page title (40 px) |
| `icon-180.png` | 180 × 180 | `icon-full-1024.png` | iPad home screen (`apple-touch-icon`) |
| `logo-256.png` | 256 × 256 | `icon-full-1024.png` (FlowGT's `logo-256.png`) | README |

Sizes of 50 px or less come from the simple drawing, larger ones from the full drawing, as in FlowGT Recorder.
