# Design assets

Everything another project needs to look like the Recording Assistant, or to show it. Copy a link from the last
column; it always points at the latest version on `main`. Files are small (the largest is about 320 KB); nothing
here is over 50 MB.

| Kind | Where |
|---|---|
| Design notes: direction, colours, type, space, component rules | [`DESIGN.md`](DESIGN.md) |
| Design tokens, day and night | [`tokens.css`](tokens.css) |
| Rendered screens, day and night | [`screenshots/`](screenshots) |
| Icon in every size | [`../assets/brand/`](../assets/brand) (kept there because the page serves it) |

To use the tokens elsewhere:

```html
<link rel="stylesheet" href="https://raw.githubusercontent.com/GabrielPower1969/recording-assistant/main/design/tokens.css">
```

Then use `var(--plate)`, `var(--key)`, `var(--rec)`, `var(--by)`, `var(--bb)` and the rest; set
`data-theme="dark"` on `<html>` to force night, or leave it unset to follow the system. Rule one of
`DESIGN.md` applies wherever they go: no coloured stripe down the side of a card.

## How the screenshots were made

Headless Chrome at 1440 × 900 against a sample project (`示例演讲`, a Chinese and an English version) kept
outside any real project, with a neutral grey fake camera and quiet pink noise as the microphone. One take was
recorded to show the recording and saved states. No real script, path or person appears in them.

## Keeping this up to date

- Change a colour, radius or font in `assets/coach.html` (between `tokens:start` and `tokens:end`), then run
  `python3 scripts/export_tokens.py`. `--check` fails when `design/tokens.css` is stale.
- Change the look: update `DESIGN.md` and retake the screenshots in the same commit.
- Add a picture: add a row to the table above.

## 中文速览

- 设计说明 `DESIGN.md`、设计变量 `tokens.css`、白天和黑夜的效果图 `screenshots/`、各尺寸图标 `../assets/brand/`。
- 表里最后一列是固定链接，复制就能用，永远指向 `main` 上的最新版。
- 别的项目要套这个外观：引用 `tokens.css`，并遵守 `DESIGN.md` 的规矩，第一条就是卡片不加侧边彩条。
- 效果图用的是示例项目和假摄像头，里面没有真实稿子、路径或人。
